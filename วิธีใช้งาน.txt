โปรแกรมถอดเสียงจากวิดีโอ
========================

1. ติดตั้ง Python 3.9 ขึ้นไป
2. เปิด Terminal/PowerShell ในโฟลเดอร์นี้
3. ติดตั้งสิ่งที่ต้องใช้:

   python -m pip install -r requirements.txt

4. ถอดเสียงวิดีโอ (ไฟล์ผลลัพธ์ TXT และ JSON จะอยู่ข้างไฟล์วิดีโอ):

   python video_transcriber.py "C:\พาธ\คลิป.mp4"

ตัวอย่างเพิ่มเติม
-----------------

ระบุว่าเสียงเป็นภาษาไทยเพื่อช่วยการถอดเสียง:
   python video_transcriber.py "คลิป.mp4" --language th

เก็บเวลาเริ่ม/จบของแต่ละคำไว้ใน JSON:
   python video_transcriber.py "คลิป.mp4" --language th --word-timestamps

เลือกโมเดล medium เพื่อความแม่นยำขึ้น (ใช้เวลาและหน่วยความจำเพิ่ม):
   python video_transcriber.py "คลิป.mp4" --model medium --language th

ระบุโฟลเดอร์ผลลัพธ์:
   python video_transcriber.py "คลิป.mp4" --output-dir "ผลลัพธ์"

สร้างเฉพาะ JSON:
   python video_transcriber.py "คลิป.mp4" --format json

ผลลัพธ์
-------

ไฟล์ .transcript.txt เป็นข้อความพร้อมเวลาเริ่มและจบของแต่ละช่วง
ไฟล์ .transcript.json เก็บข้อความเต็ม ภาษา ระยะเวลา และข้อมูลแยกแต่ละช่วง
รวมถึงค่าความน่าจะเป็นที่ Whisper ให้มา เพื่อใช้กรอง/วิเคราะห์ต่อ

หมายเหตุ
-------

- ครั้งแรกที่ใช้โมเดล โปรแกรมจะดาวน์โหลดโมเดลจากอินเทอร์เน็ต
- โมเดล small เป็นค่าเริ่มต้น; เลือก medium หรือ large-v3 ได้เมื่อเครื่องมีทรัพยากรพอ
- ใช้ --device cuda เมื่อต้องการระบุ GPU NVIDIA; ค่าเริ่มต้น auto จะเลือกให้อัตโนมัติ
- โปรแกรมไม่สร้างชื่อผู้พูดอัตโนมัติ หากต้องการแยกผู้พูดต้องเพิ่มระบบ diarization
